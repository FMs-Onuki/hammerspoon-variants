# タイル型ウィンドウマネージャ

タイリングとアプリ切替をキーボードだけで行う Hammerspoon 設定。

「同じキーをもう一度押すと次へ進む」動きを全体で統一している。

## キー

修飾キーは役割で2層に分ける。⌥ = ウィンドウとアプリ、⌃⌥ = スナップ。

### アプリ（⌥+英字）

未起動なら起動、背面なら前面化する。すでに前面なら、同じアプリの次のウィンドウへ移る（別デスクトップのウィンドウを含む）。

| キー | アプリ |
|---|---|
| ⌥C | Chrome |
| ⌥V | VS Code |
| ⌥P | PyCharm |
| ⌥T | cmux |
| ⌥A | Claude |
| ⌥X | Codex |
| ⌥S | Slack |
| ⌥G | Sourcetree |

### アプリのまとまり（⌥+数字）

まとまりのアプリだけを表示して整列し、他のアプリは隠す。先頭のアプリがメイン（左の大きい領域）になる。
続けて押すと、まとまりの中でウィンドウを順にフォーカスする。

| キー | まとまり |
|---|---|
| ⌥1 | VS Code + cmux |
| ⌥2 | PyCharm + cmux |
| ⌥3 | Chrome + Claude |

### ウィンドウ操作（⌥）

| キー | 動作 |
|---|---|
| ⌥H / J / K / L | 左 / 下 / 上 / 右のウィンドウへフォーカス |
| ⌥⇧H / J / K / L | その方向のウィンドウと位置を交換 |
| ⌥Enter | 整列。続けて押すとレイアウトを切替（メイン+スタック → 横等分 → 全最大化） |
| ⌥⇧Enter | フォーカス中のウィンドウをメインにする |
| ⌥[ / ⌥] | メイン領域を狭く / 広く |
| ⌥⇧Space | フロート切替（整列の対象から外す / 戻す） |

### スナップ（⌃⌥）

| キー | 動作 |
|---|---|
| ⌃⌥← / → / ↑ / ↓ | 左 / 右 / 上 / 下に配置。続けて押すと 1/2 → 2/3 → 1/3 |
| ⌃⌥Enter | 最大化 |
| ⌃⌥C | 中央に配置 |
| ⌃⌥G | グリッドで手動配置 |
| ⌃⌥T | 自動整列の ON / OFF（ウィンドウの増減に合わせて整列し直す） |
| ⌃⌥S | 今のウィンドウ配置を保存する（全画面・全アプリ） |
| ⌃⌥L | 保存した配置に戻す。アプリとウィンドウ名で照合する |
| ⌃⌥R | 設定の再読み込み |

## 導入と復元

リポジトリのルートで実行する。他の設定と組み合わせる方法は[ルートの README](../../README.md) を参照する。

```sh
./install.sh tiling-wm   # 導入（既存の init.lua を退避）
./install.sh --uninstall  # 退避した init.lua を復元
```

## windows-compat と組み合わせた場合

windows-compat は ⌥ を Win キー（⌥←/→、⌥1〜9、⌥E 等）として使う。
組み合わせて導入すると、キーが重ならないよう本設定の修飾キーが次のように変わる。キー自体は同じである。

| 単独 | 組み合わせ時 | 例 |
|---|---|---|
| ⌥ | ⌃⌥ | ⌃⌥C で Chrome、⌃⌥1 でまとまり、⌃⌥H でフォーカス移動 |
| ⌥⇧ | ⌃⌥⇧ | ⌃⌥⇧H で入替、⌃⌥⇧Enter でメインにする |
| ⌃⌥ | ⌃⌥⌘ | ⌃⌥⌘← で左に配置、⌃⌥⌘R で再読み込み |

組み合わせ時の修飾キーは `init.lua` の `COMBINED_MOD` / `COMBINED_MOD_SHIFT` / `COMBINED_SNAP_MOD` で変更できる。

## カスタマイズ

`init.lua` 冒頭の変更箇所を編集する。

- `APPS` / `APP_KEYS`: アプリとキーの対応
- `GROUPS`: まとまりの組み合わせ（先頭がメイン）
- `GAP`: ウィンドウ間の隙間、`MAIN_RATIO`: メイン領域の初期幅
- `EXCLUDE_APPS`: 整列の対象外とするアプリ
- `MOD` / `MOD_SHIFT` / `SNAP_MOD`: 修飾キー（`COMBINED_*` は windows-compat と組み合わせたとき）

アプリの bundle ID は次のコマンドで確認できる。

```sh
osascript -e 'id of app "Codex"'
```

## 注意事項

- アクセシビリティ権限が必要である（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。
- ⌥+英字を使うため、そのキーで入力される特殊文字（˙ ∆ 等）は入力できなくなる。
- 整列の対象は、今のデスクトップ・フォーカス中の画面にあるウィンドウである。
- ターミナル等の文字単位でリサイズするアプリは、枠との間に少し隙間が出る。
- 配置の復元は、今のデスクトップにあるウィンドウが対象である。保存は1組だけで、保存し直すと上書きされる。
