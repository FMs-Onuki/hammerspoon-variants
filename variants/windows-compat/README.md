# Windows互換モード

Windows のキー操作を macOS 上で再現する Hammerspoon 設定。
一時的に Mac を使用する Windows ユーザーを対象とする。

## キーの対応方針

キーは刻印ではなく物理位置で対応させる。

| 位置 | Windows のキー | Mac のキー | 本設定での役割 |
|---|---|---|---|
| 左下隅 | Ctrl | ⌃ control | Ctrl 系ショートカット |
| Ctrl の右 | Win | ⌥ option | Win 系ショートカット |
| スペースの横 | Alt | ⌘ command | Alt+Tab / Alt+F4 |

## 機能

| キー | 動作 | Windows の対応操作 |
|---|---|---|
| ⌃C / ⌃V / ⌃X / ⌃Z / ⌃A / ⌃S / ⌃F 等 | ⌘ に変換 | Ctrl+C 等 |
| ⌃Y | やり直し（⌘⇧Z） | Ctrl+Y |
| Home / End | 行頭 / 行末（⇧ で選択） | Home / End |
| ⌃Home / ⌃End | 文書の先頭 / 末尾 | Ctrl+Home / End |
| ⌃← / ⌃→ | 単語移動（⇧ で選択） | Ctrl+← / → |
| ⌃Backspace | 単語削除 | Ctrl+Backspace |
| ⌘Tab（⇧ で逆順） | ウィンドウ単位の切替 | Alt+Tab |
| ⌘F4 | ウィンドウを閉じる（最後のウィンドウであればアプリを終了） | Alt+F4 |
| ⌥← / ⌥→ / ⌥↑ | ウィンドウを左半分 / 右半分 / 最大化 | Win+← / → / ↑ |
| ⌥↓ | スナップ前のサイズに戻す（スナップしていなければ最小化） | Win+↓ |
| ⌥D | デスクトップ表示の切替（表示中のアプリを隠す / 再表示する） | Win+D |
| ⌥E | ホームフォルダを Finder で開く | Win+E |
| ⌥L | 画面をロック | Win+L |
| ⌥R | ファイル名を指定して実行（アプリ名・パス・URL を開く） | Win+R |
| ⌥V | クリップボード履歴（直近20件）から選択して貼り付け | Win+V |
| ⌥1〜⌥9 | `TASKBAR_APPS` のアプリを起動・前面化。前面のアプリではウィンドウを巡回 | Win+1〜9 |
| F5 | 再読み込み（⌘R）。除外アプリでは変換しない | F5 |
| ⌥/ | キー対応表を表示（初回の読み込み時にも表示） | — |
| ⌃⌥⌘W / メニューバーの Win 表示をクリック | 有効 / 無効の切替 | — |

## 導入と復元

リポジトリのルートで実行する。他の設定と組み合わせる方法は[ルートの README](../../README.md) を参照する。

```sh
./install.sh windows-compat   # 導入（既存の init.lua を退避）
./install.sh --uninstall      # 退避した init.lua を復元
```

一時的に無効化する場合は、メニューバーの表示を Mac に切り替える。
本設定は macOS のシステム設定を変更しない。Hammerspoon を終了すると、すべての変換が解除される。

## カスタマイズ

`init.lua` 冒頭の変更箇所を編集する。

- `CTRL_TO_CMD`: ⌘ に変換するキー
- `EXCLUDE_APPS`: Ctrl 系の変換の対象外とするアプリの bundle ID（Win 系のショートカットは除外しない）
- `TASKBAR_APPS`: ⌥1〜⌥9 に割り当てるアプリ（上から順に ⌥1, ⌥2, …）。初期値は Finder、Edge、Outlook、Teams、
  Word、Excel、PowerPoint、VSCode、ターミナル。未インストールのアプリは代替のアプリ（Chrome、メール、Slack 等）を用いる
- `CLIP_MAX`: クリップボード履歴の保持件数
- `SHOW_CHEATSHEET_ON_FIRST_LOAD` / `CHEATSHEET_SECONDS`: キー対応表の初回表示と表示秒数

キー対応表の初回表示をやり直す場合は、Hammerspoon コンソールで
`hs.settings.clear("WinCompat.cheatsheetShown")` を実行してから再読み込みする。

アプリの bundle ID は次のコマンドで確認できる。

```sh
osascript -e 'id of app "iTerm"'
```

## 除外アプリの例

ターミナルでは ⌃C がプロセスの中断に割り当てられている。変換を適用すると ⌘C（コピー）となり中断できなくなるため、
Terminal / iTerm2 / cmux / Ghostty / Warp / kitty / WezTerm / Alacritty を初期設定で除外している。

## 注意事項

- アクセシビリティ権限が必要である（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。
- パスワード入力欄などのセキュア入力中は、macOS の仕様により変換が適用されない。
- Mac 内蔵キーボードの F4 / F5 は特殊キーとして動作するため、⌘F4 と F5 は fn を併用して入力する。
  または、システム設定で「F1、F2 などのキーを標準のファンクションキーとして使用」を有効にする。
- ⌥ と矢印・D・E・L・R・V・数字・/ の組み合わせは Win 系のショートカットとして扱うため、⌥ による記号入力や
  ⌥← / ⌥→ による単語移動（ターミナルを含む）は使用できない。単語移動には ⌃← / ⌃→ を用いる。
- クリップボード履歴は hs.settings に保存される。パスワードマネージャが記録対象外と指定した内容は保存しない。
- 除外アプリ以外では、⌃ 系の macOS 標準ショートカット（⌃A / ⌃E による行頭・行末移動等）は使用できない。
- VSCode の統合ターミナルはアプリ単位で判別できないため、変換の対象となる。
- ⌃← / ⌃→ は macOS 標準のデスクトップ切替と同じキーである。単語移動ではなくデスクトップが切り替わる場合は、
  システム設定 → キーボード → キーボードショートカット → Mission Control で該当項目を無効にする。
