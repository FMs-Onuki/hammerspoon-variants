# ウィンドウマネージャ

⌥+数字でアプリを切り替え、⌥+キーでウィンドウの位置と大きさを変える Hammerspoon 設定。

「同じキーをもう一度押すと次へ進む」動きで統一している。

## キー

### アプリ（⌥1〜⌥8）

未起動なら起動、背面なら前面化する。すでに前面なら、同じアプリの次のウィンドウへ移る。
ウィンドウが別のデスクトップにあればそのデスクトップへ切り替え、最小化されていれば元に戻す。

別のデスクトップへの切り替えには、システム設定 → デスクトップとDock →
「アプリケーションの切り替えで、アプリケーションのウインドウが開いているスペースに移動」をオンにしておく。
オフのままだと、別のデスクトップにあるウィンドウは切り替え先に表示されない。

| キー | アプリ |
|---|---|
| ⌥1 | VS Code |
| ⌥2 | PyCharm |
| ⌥3 | cmux |
| ⌥4 | Sourcetree |
| ⌥5 | Slack |
| ⌥6 | Chrome |
| ⌥7 | Claude |
| ⌥8 | メモ |

### ウィンドウ（⌥9 / ⌥0 / ⌥- / ⌥M）

フォーカス中のウィンドウを対象とする。

| キー | 動作 |
|---|---|
| ⌥9 | 左に配置。続けて押すと幅が 1/2 → 2/3 → 1/3 |
| ⌥0 | 右に配置。続けて押すと幅が 1/2 → 2/3 → 1/3 |
| ⌥- | 最大化。最大化中に押すと元の大きさに戻す |
| ⌥M | 最小化（Dock にしまう）。⌥+数字でそのアプリを選ぶと元に戻る |

## 導入と復元

リポジトリのルートで実行する。他の設定と組み合わせる方法は[ルートの README](../../README.md) を参照する。

```sh
./install.sh window-manager    # 導入（既存の init.lua を退避）
./install.sh --uninstall       # 退避した init.lua を復元
```

## windows-compat と組み合わせた場合

windows-compat は ⌥ を Win キー（⌥←/→、⌥1〜9、⌥E 等）として使う。
組み合わせて導入すると、キーが重ならないよう本設定の修飾キーが ⌥ から ⌃⌥ に変わる。
キー自体は同じである（例: ⌃⌥1 で VS Code、⌃⌥9 で左に配置）。

組み合わせ時の修飾キーは `init.lua` の `COMBINED_MOD` で変更できる。

## カスタマイズ

`init.lua` 冒頭の変更箇所を編集する。

- `APPS` / `APP_KEYS`: アプリとキーの対応
- `WINDOW_KEYS`: 左右の配置・最大化・最小化のキー
- `MOD`: 修飾キー（`COMBINED_MOD` は windows-compat と組み合わせたとき）

アプリの bundle ID は次のコマンドで確認できる。

```sh
osascript -e 'id of app "Codex"'
```

本設定は `hs.window.animationDuration` を 0 にする（ウィンドウを動かすときのアニメーションをなくす）。
Hammerspoon 全体に効くため、他の設定でもアニメーションはなくなる。

## 注意事項

- アクセシビリティ権限が必要である（システム設定 → プライバシーとセキュリティ → アクセシビリティ）。
- ⌥+数字・⌥- ・⌥M で入力される特殊文字（¡ ™ – µ 等）は入力できなくなる。
- ターミナル等の文字単位でリサイズするアプリは、枠との間に少し隙間が出る。
- Hammerspoon を起動・再読み込みしてからまだ表示していないデスクトップのウィンドウは、
  ⌥+数字の巡回の対象に入らない。そのデスクトップを一度表示すると対象に入る。
